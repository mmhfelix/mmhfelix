# 尋光之旅 — 華容道攤位遊戲

供室內攤位用 iPad Pro（橫放）遊玩的華容道網站。共三關，必須逐關完成；完成第三關後輸入暱稱，登上龍虎榜。

純靜態網頁（HTML／CSS／JavaScript），不需要伺服器或資料庫；首次載入後可離線遊玩。

## 玩法及規則

| 項目 | 規則 |
|---|---|
| 目標 | 把發光的小羊（2×2）移到底部中間的出口 |
| 操作 | 用手指拖動方塊；方塊只可向一個方向移動時，輕按即可；可移向多個方向時，輕按方塊偏向想去的一邊 |
| 步數 | 同一件方塊連續移動（包括轉彎）只計 1 步 |
| 計時 | 每關按「開始」後才計時，棋子亦在此時才出現 |
| 時限 | 第一關 4 分鐘、第二關 5 分鐘、第三關 6 分鐘（管理頁可調）；超時即結束挑戰 |
| 龍虎榜 | 只限完成三關者；按三關用時總和排名，同時間比總步數 |
| 撤銷／重新排列 | 不影響計時；重新排列會把步數歸零 |
| 閒置 | 2 分鐘無人操作會彈出「仍在玩嗎？」，再過 15 秒返回主頁 |

### 關卡（已用解題程式驗證）

| 關卡 | 佈局（由上至下） | 最少步數 | 空格 |
|---|---|---|---|
| 第一關「黑夜」 | `SBBS SBBS .... V..V VHHV` | 7 | 6 |
| 第二關「破曉」 | `VBBV VBBV VSSV VHHV ....` | 12 | 4 |
| 第三關「晨光」 | `VSSV VBBV VBBV VSSV .HH.` | 22 | 2 |

參考：經典「橫刀立馬」最少要 81 步。

## 在 iPad 上使用

1. 用 Safari 開啟網站網址，按「分享」→「加入主畫面」，之後從主畫面圖示開啟（全螢幕、可離線）。
2. 首次開啟時請連上網絡，並把三關玩一次，確保所有檔案已存入 iPad。
3. 「設定」→「螢幕顯示與亮度」→「自動鎖定」設為「永不」，並全日接駁電源。
4. 「設定」→「輔助使用」→「引導使用模式」開啟；開啟遊戲後連按三下頂端按鈕（有主畫面按鈕的型號則按主畫面按鈕），鎖定在遊戲畫面。
5. 不要使用私密瀏覽，否則龍虎榜無法保存。

## 管理頁

在主頁長按「尋光之旅」標題 2 秒，輸入密碼（預設 `2468`，在 `js/config.js` 修改）。

- 查看及刪除個別紀錄（例如不雅暱稱）
- 匯出 CSV（iPad 會開啟分享選單，可存到「檔案」或 AirDrop）、複製 CSV
- 清除全部紀錄
- 調整每關時限（每次 ±30 秒）

龍虎榜只儲存在該部 iPad 的瀏覽器內。清除 Safari 網站資料、改用私密瀏覽或更換 iPad 都會令紀錄消失，請每日收檔前匯出備份。

## 更換圖片

把新圖片放進 `assets/`，然後在 `js/config.js` 的 `images` 或 `levels[].background` 改成新檔名（或用同名檔案直接覆蓋）。PNG、JPG、WebP、SVG 均可。

| 用途 | 現時檔案 | 比例 | 建議尺寸 |
|---|---|---|---|
| 主頁背景 | `assets/bg-home.svg` | 4:3 橫向 | 2732 × 2048 |
| 第一關背景 | `assets/bg-level1.svg` | 4:3 橫向 | 2732 × 2048 |
| 第二關背景 | `assets/bg-level2.svg` | 4:3 橫向 | 2732 × 2048 |
| 第三關背景 | `assets/bg-level3.svg` | 4:3 橫向 | 2732 × 2048 |
| 棋盤底 | `assets/board.svg` | 4:5 直向（會拉伸至此比例） | 1200 × 1500 |
| 出口光暈 | `assets/exit.svg` | 約 16:7，透明背景 | 960 × 420 |
| 小羊（2×2） | `assets/lamb.svg` | 1:1 | 800 × 800 |
| 樹（直向 1×2） | `assets/tree.svg` | 1:2 | 400 × 800 |
| 木頭（橫向 2×1） | `assets/log.svg` | 2:1 | 800 × 400 |
| 石頭（1×1） | `assets/rock.svg` | 1:1 | 400 × 400 |
| 主畫面圖示 | `icons/icon-180.png`、`icon-192.png`、`icon-512.png` | 1:1 | 180、192、512 |

注意：

- 方塊圖片會填滿整格並切成圓角，重要內容請放在中間約 85% 範圍內。
- 背景以「填滿畫面」顯示：11 吋 iPad 比 4:3 闊，上下邊緣會被裁去少許，重要內容請放中間。
- 個別關卡可用另一套方塊圖片：在該關加上 `pieces: { V: 'assets/另一款樹.png' }`。
- 新增或改名的檔案，要一併加進 `sw.js` 的 `FILES`，並把 `CACHE` 版本號加一，否則離線時找不到。

## 更改文字、經文及關卡

全部在 `js/config.js`：標題、說明、每關名稱、經文（現用和合本）、佈局、時限、龍虎榜名次數目、暱稱字數上限、管理密碼、閒置秒數。

- 佈局符號：`B` 小羊（2×2，必須剛好一隻）、`V` 樹（直 1×2）、`H` 木頭（橫 2×1）、`S` 石頭（1×1）、`.` 空位。
- 改動佈局後執行測試，確認有解及最少步數（`tests/levels.test.js` 內的預期步數要一併更新）。
- 改動標題或經文等文字後，執行 `bash tools/update-fonts.sh` 重新製作宋體字型；否則新字會以系統字型顯示。

## 測試

```bash
node --test tests/*.test.js                  # 遊戲邏輯及關卡（有解、步數、圖片齊全）
NODE_PATH=$(npm root -g) node tests/e2e.js   # 用瀏覽器實際拖動玩完三關（需要 Playwright）
```

## 部署（Netlify）

發佈資料夾為 `huarong-dao/`，不需要建置指令。任何提供 HTTPS 的靜態網站寄存服務都可以（離線功能需要 HTTPS）。

## 檔案

```
index.html             頁面結構
css/style.css          版面及配色
js/config.js           所有可修改設定
js/core.js             華容道規則及解題程式（純邏輯）
js/app.js              畫面、操作、計時、龍虎榜、管理頁
sw.js                  離線快取
assets/                背景及方塊圖片
fonts/                 思源宋體子集（Noto Serif HK，SIL Open Font License）
icons/                 主畫面圖示
tools/update-fonts.sh  重新製作字型子集
tests/                 自動測試
```
